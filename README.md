# Purity Cherus — Personal Portfolio Website

A responsive student portfolio built with semantic HTML5, external CSS3 and JavaScript.

## Files (5)
1. `index.html` — Home, About, Skills, Projects and Contact sections.
2. `style.css` — page styling, layout, hover effects and responsive design.
3. `script.js` — mobile navigation and contact-form validation.
4. `images/profile.jpg` — profile photo supplied for this portfolio.
5. `README.md` — project and submission guide.

## Open on Android with Acode
1. Download and extract the ZIP.
2. Open the extracted `Purity_Cherus_Portfolio` folder in Acode.
3. Open `index.html`.
4. Use Preview / Open in browser.
5. Keep the HTML, CSS, JavaScript and `images` folder together.

- Check that the three practice-project descriptions match work you have actually completed.
